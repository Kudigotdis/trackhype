Implementation principle Store event-level activity first. Derive dashboard metrics from events so new intelligence can be added later without redesigning the underlying tracking model.
YouTube measurement note

TrackHype should treat YouTube embed activity as observed TrackHype player interaction. Use YouTube IFrame Player API state changes plus periodic current-time sampling while playback is active. Do not label the data as proof of human attention or as complete YouTube channel analytics.
