# ZIMBABWE MUSIC GENRE DIRECTORY

A searchable, app-friendly genre taxonomy designed for a music chart application.

## Recommended information architecture

**Browse path**

`Music Family → Genre → Artist → Song → Chart Entry`

**Search path**

A single search box should search:

- Genre name
- Music family
- Artist name
- Genre keywords

## Data model

Each genre contains:

- `id` — stable machine-readable identifier
- `name` — display name
- `family_id` — parent category
- `description` — short user-facing explanation
- `artist_count` — quick UI statistic
- `artists[]` — representative artists/groups
- `search_terms[]` — precomputed search index terms

## Important relationship rule

Artists are intentionally allowed to appear in multiple genres. The chart app should eventually maintain artist profiles separately and use relationships:

`genre ↔ artist ↔ song ↔ chart_entry`

The current JSON preserves the source taxonomy's artist associations exactly as supplied.
